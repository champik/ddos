# DDOS Brand Rules

## Контент

**Дозволено:**
- Funny moments, fails, unexpected outcomes
- Rage (без хейту), wholesome, impressive plays
- IRL funny moments
- Just Chatting chaos
- Gaming highlights (будь-яка гра крім заборонених)
- Mild profanity в gaming context

**ЗАБОРОНЕНО — автоматично відхиляти:**
- Будь-який Russian/RU контент
- Gambling / Casino / Slots
- Слюри / hate speech
- Explicit sexual content
- Harassment цілеспрямований

## Tone of voice

**Канал:** Comfort + humor + internet chaos + editorial pacing  
**Відчуття:** смішно, комфортно, курований, binge-friendly  
**НЕ:** TikTok brainrot, esports only, raw compilation, overproduced

## Hooks стиль — sarcastic anticipation

Хороші хуки:
- THIS LOOKED FINE AT FIRST
- HE REALLY THOUGHT THIS WOULD WORK
- ABSOLUTELY NOTHING COULD GO WRONG
- NOT WHAT HE EXPECTED
- WAIT FOR IT
- THIS GOT WORSE FAST

Погані хуки:
- FUNNY MOMENT (занадто generic)
- HE SCREAMED (спойлер)
- WATCH THIS (нічого не говорить)

## Thumbnail text стиль

- 2–4 слова ALL CAPS
- Emotional implication
- Приклади: NO WAY / HE LOST IT / ONE HP / IT GOT WORSE / NOT TODAY

## Episode structure

```
[INTRO 1.25s] → [OPENER — сильний кліп] → [SEGMENT 1] → [RECONNECTING] → [SEGMENT 2] → ... → [CLOSER — сильний] → [COOLDOWN якщо є] → [OUTRO 1.25s]
```

## Shorts rules

- Standalone — має бути зрозумілий без контексту
- Починається швидко (перші 2s = hook)
- Субтитри обов'язково (word-by-word)
- Довжина: 20–45 секунд ідеально
